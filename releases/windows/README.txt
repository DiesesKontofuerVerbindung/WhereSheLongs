Where She Longs — Windows 提交版

运行方式
1. 解压整个 ZIP。
2. 双击 Where She Longs.exe。
3. 如果 Windows SmartScreen 提示，请在确认文件来源后选择“更多信息”→“仍要运行”。
4. 第一次启动可能需要等待资源加载，请勿连续重复启动。

基本操作
- 推进对白：Space / Enter
- 移动：A / D 或 左右方向键
- 跑酷：Space 跳跃，S / 下方向键下滑
- LakeJump：按住鼠标左键、Space 或 Enter 蓄力，松开起跳
- StarJar：拖动五团星光进入瓶口
- 无摄像头时：剧情明确提示眨眼的终点可按 F8 继续

发布设置
- 已关闭 F3/F4 和跑酷 F1–F6 开发者快捷键。
- 已隐藏全局 Blink 状态和跑酷状态调试覆盖层。
