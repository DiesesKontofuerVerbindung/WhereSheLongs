# Codex Entry Instructions

1. Read `skills.md` completely.
2. Read `ARCHITECTURE.md`.
3. Identify whether the task belongs to Forest, Wedding, or Shared infrastructure.

`skills.md` is the project-specific working contract. Treat it as mandatory repository guidance.
