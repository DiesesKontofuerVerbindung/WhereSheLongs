# 河上跳石 (River Jump) — Godot 源码

对应可玩包：`godot-river-jump-demo/godot-river-jump-demo.zip` 里的 `RiverJumpDemo.exe`

## 打开方式
1. 安装 Godot **4.7.x**
2. 用编辑器打开本文件夹（含 `project.godot`）
3. 按 F5 运行

## 主要文件
- `main.tscn` — 入口
- `levels/river_jump.tscn` — 玩法关卡
- `levels/light_child.gd` — 人物 / 小光人 / 倒影
- `assets/` — 贴图与 shader
